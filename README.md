# อนาคตวํโส: คัมภีร์อนาคตวงศ์ ฉบับคาถา (ฉบับ PTS 1886) บาลีอักษรไทย

**อ่านออนไลน์:** <https://korakot.github.io/anagatavamsa/> · **PDF (A5):** [anagatavamsa-thai-a5.pdf](anagatavamsa-thai-a5.pdf) · [English](README.en.md)

คัมภีร์อนาคตวงศ์ฉบับคาถา ๑๔๒ คาถา ของพระกัสสปเถระ ว่าด้วยพระศรีอริยเมตไตรย พระพุทธเจ้าในอนาคต ปริวรรตเป็นอักษรไทยจากฉบับที่ J. Minayeff ชำระ พิมพ์ใน *Journal of the Pali Text Society* ปี 1886 หน้า ๔๑–๕๓ (ฉบับ PTS) ซึ่งเป็นสาธารณสมบัติ

ต่างจาก "อนาคตวงศ์" ฉบับร้อยแก้วที่แต่งในประเทศไทยว่าด้วยพระพุทธเจ้าในอนาคต ๑๐ พระองค์ (เช่นฉบับหอสมุดแห่งชาติ ๒๕๔๐) ซึ่งเป็นคนละคัมภีร์

## ไฟล์

- `index.html`: หน้าอ่านออนไลน์ อ่านบนมือถือได้ สลับอักษรไทยกับอักษรโรมันได้
- `anagatavamsa-thai-a5.pdf`: ฉบับพิมพ์ขนาด A5 ๑๗ หน้า
- `data/verse.tsv`: ข้อมูลทีละบาท (๕๙๐ บาท) คอลัมน์ `key` (เช่น `v12.3` = คาถาที่ ๑๒ บาทที่ ๓), `verse`, `pada`, `page` (หน้าในฉบับ PTS), `roman`, `thai`

## ทำอย่างไร

1. ถอดตัวอักษรโรมันจากภาพสแกนฉบับพิมพ์ทุกหน้า
2. เทียบทีละอักษรกับฉบับชำระของ K. R. Norman (*JPTS* 28, 2006) ซึ่งบันทึกคำอ่านของ Minayeff ไว้ในเชิงอรรถทุกแห่งที่แก้ จุดที่ไม่ตรงกันทุกจุดตรวจกับภาพสแกนขยาย
3. คงตัวสะกดตามฉบับพิมพ์ แก้เฉพาะคำพิมพ์ผิดที่ชัดเจน ๓ แห่ง (คาถาที่ ๓๐, ๓๑, ๓๙)
4. ปริวรรตเป็นอักษรไทยด้วย [axorn](https://github.com/korakot/axorn) ตามแบบพระไตรปิฎกฉบับ VRI (พินทุ นิคหิต)

ทำโดยใช้ AI ช่วย ยังไม่มีผู้ตรวจทานอิสระ จึงยังเป็นฉบับร่าง ถ้าพบจุดผิด แจ้งได้ที่ [GitHub issues](https://github.com/korakot/anagatavamsa/issues)

## ฉบับอื่นที่ควรรู้

- พระมหาชนะ ธมฺมธโช (ภมรพล), *อนาคตวํส คัมภีร์อนาคตวงศ์ พระอริยเมตไตรย* (๒๕๔๓): บาลีอักษรไทยพร้อมคำแปล ปริวรรตและแปลจากฉบับอักษรโรมันของ U Chit Tin & W. Pruitt (1988)
- K. R. Norman, "The Anāgatavaṃsa Revisited", *JPTS* 28 (2006): ฉบับชำระใหม่พร้อมคำแปลภาษาอังกฤษ
